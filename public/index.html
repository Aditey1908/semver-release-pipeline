How a change becomes a release

  1. CommitConventional Commit message checked by commitlint
  2. Quality gateLint, unit + API tests, coverage, build, Docker smoke test
  3. Semantic releaseNext version from commits → CHANGELOG, Git tag, GitHub Release
  4. Container imageMulti-arch image pushed to GHCR as x.y.z, x.y, x, latest
  5. StagingReleased image deployed with Compose and smoke-tested
  6. ProductionApproved deploy of the same image, verified by version
